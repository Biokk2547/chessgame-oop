===================================================================
               🎮 ยินดีต้อนรับสู่ CHESS GAME OOP ♟️
===================================================================

วิธีเริ่มเล่นเกมง่ายๆ:
1. ดับเบิ้ลคลิกที่ไฟล์ "Play.bat" หรือ "Play_Silent.vbs" เพื่อเริ่มเล่นได้ทันที!
   (หรือดับเบิ้ลคลิกที่ไฟล์ "ChessGame.jar" ได้โดยตรง)
2. หากต้องการเล่นแบบหน้าจอ Console (ข้อความในหน้าต่างดำ) ให้ดับเบิ้ลคลิก "Play_Console_Mode.bat"

-------------------------------------------------------------------
ความต้องการของระบบ (System Requirements):
-------------------------------------------------------------------
- ระบบปฏิบัติการ: Windows 10 / 11 (64-bit)
- Java Runtime: Java 11 หรือสูงกว่า (แนะนำ Java 17 หรือ Java 21 LTS)
  หากยังไม่มี Java สามารถดาวน์โหลดได้ฟรีที่: https://adoptium.net/

-------------------------------------------------------------------
โหมดการเล่นภายในเกม:
-------------------------------------------------------------------
1. 👤 vs 🤖 เล่นกับ AI Bot (เลือกสไตล์การเล่นและระดับความยากได้):
   - AGGRESSIVE: เน้นบุกโจมตีอย่างดุดัน
   - DEFENSIVE: วางแผนป้องกันรัดกุม
   - POSITIONAL: เน้นการคุมพื้นที่และเปรียบเทียบรูปหมาก
   - TACTICAL: เน้นการจับกินหมากและแท็กติกเฉียบคม
   - MASTER / STOCKFISH: อัจฉริยะวิเคราะห์ลึกระดับปรมาจารย์

2. 👑 BOSS BATTLE (โหมดสู้บอส):
   - ด่านที่ 1: EvilBox (The Trickster)
   - ด่านที่ 2: Pirate Cat (The Marauder)
   - ด่านที่ 3: Witch Kitty (The Spellcaster)
   - ด่านที่ 4: Vampire Lord (The Crimson Monarch)

3. 🧩 PUZZLE SYSTEM (แก้ปริศนาหมากรุก):
   - แบบฝึกหัดและปริศนาหมากรุกมากกว่า 100+ รูปแบบให้ฝึกฝน

4. 📊 GAME REVIEW & ANALYSIS (วิเคราะห์เกมย้อนหลัง):
   - ระบบทบทวนเกม แสดงความแม่นยำ (Accuracy %), กราฟความได้เปรียบ (Advantage Graph),
     และจำแนกตาเดิน (Brilliant, Great, Best, Excellent, Good, Inaccuracy, Mistake, Blunder)

-------------------------------------------------------------------
การควบคุมกระดานหมากรุก (Controls):
-------------------------------------------------------------------
- ลากแล้วปล่อย (Drag & Drop): คลิกซ้ายค้างที่ตัวหมากแล้วลากไปยังช่องปลายทาง
- คลิกเพื่อเดิน (Click-to-Move): คลิกเลือกตัวหมาก จะแสดงจุดตำแหน่งที่เดินได้ แล้วคลิกช่องเป้าหมาย
- คลิกขวา (Right-Click): ยกเลิกการเลือกหมาก
- ปุ่มคำสั่งด้านล่าง:
  * 💡 Hint: ขอคำแนะนำตาเดินที่ดีที่สุดจาก AI
  * ↶ Undo: กดย้อนกลับตาเดิน
  * ↷ Redo: เดินไปข้างหน้า
  * 📊 Eval Bar: สลับเปิด/ปิดแถบประเมินแต้มได้เปรียบ
  * 🏳️ Surrender: กดยอมแพ้

ขอให้สนุกกับการเล่นเกม Chess Game OOP!
